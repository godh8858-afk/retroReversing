# Donkey Kong Classics NES — Custom v6 (Experimental)

This is a **ROM hack patch only**. The original copyrighted NES ROM is **not** included.

**Download:** [DK_Classics_Mario_Midair_Jump_v6.ips](./DK_Classics_Mario_Midair_Jump_v6.ips)

## Intended changes
- **Donkey Kong (Mario):** Press A while airborne for another jump; release and press A again to repeat.
- **Donkey Kong (Mario):** B-button fireball attack, SELECT hammer on/off, and ladder-climbing-with-hammer modifications.
- **Donkey Kong Jr.:** B-button punch, midair jumping, and slight movement-speed adjustments.
- Other earlier experimental changes include collision/invincibility behavior.

## Install
1. Obtain your own legal copy of **Donkey Kong Classics (USA, Europe)** for NES.
2. Back it up.
3. Apply the IPS file to a clean, unmodified copy with a compatible IPS patcher (e.g. Floating IPS / FLIPS).
4. Open the patched NES file in FCEUX or Mesen.
