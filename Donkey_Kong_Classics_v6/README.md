# Donkey Kong Classics — experimental v6 mod

Download: [DK_Classics_v6_Public_IPS_Patch.zip](./DK_Classics_v6_Public_IPS_Patch.zip)

**IPS patch only.** This release does not contain a copyrighted NES ROM. Use your own lawfully obtained `Donkey Kong Classics (USA, Europe).nes` copy and a tool such as Floating IPS to apply the patch. Original ROM MD5: `074fea160b7ec513bdaf2c0bb042c262`. Modified gameplay is experimental and not confirmed with full emulator playtesting.

Includes Mario repeated A-button midair jumps, B-button fireballs, SELECT hammer toggle, and ladder changes; Donkey Kong Jr. B-button punch, speed changes, and repeated jumps.
