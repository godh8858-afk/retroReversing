# Donkey Kong Classics — v6 experimental mod

**[Download the v6 IPS patch](./DK_Classics_Mario_Midair_Jump_v6.ips)** (patch only, no game ROM).

Apply the IPS patch to your own lawfully obtained copy of `Donkey Kong Classics (USA, Europe).nes` using Floating IPS. Expected original MD5: `074fea160b7ec513bdaf2c0bb042c262` (49168 bytes). The patch has been verified to reproduce the modded NES ROM from that base; gameplay has not been fully tested.

Features targeted: Mario B-button fireballs, SELECT hammer toggle, ladder climbing with hammer, slightly faster movement, immunity to fireball enemies, and repeated A-button midair jumps; Donkey Kong Jr. punch, speed boost and repeated midair jumps. All are experimental.
